# Changes

## 0.2.0 — local offline beta

- Replaced the cloud planner with a local, camera-aware lighting engine.
- Three distinct editable Arnold rigs; recommended look first.
- Local preview exposure tuning, with at most one correction per check.
- Reduced initial references from three rendered frames to one; animation bounds still use three sampled frames.
- Preserved scene-change guards, native shadows, Original, Stop, Undo and creator credit.
- Refresh loaded modules when installing an update.
- Reject watermarked previews for automatic exposure decisions, including when later native license messages are quiet.
- First beta release of the independent offline lighting engine.
